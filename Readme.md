## E-Learning
The E-learning project is an AI-driven online learning platform aimed at delivering a personalized learning experience for each user. 
GitHub

## Purpose & Vision

The platform is built to tailor education to individual users — rather than a “one size fits all” model — by using intelligence to recommend relevant content and learning paths. 
It seeks to make learning more effective by guiding students toward courses or materials that best fit their profile skills, interests, or background.
